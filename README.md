## Task 3 Description

In this task, I created a nested list named `data`. This list stores multiple values in a structured format.

After that, I created a copy of the `data` list and stored it in a new list called `update_data`. The purpose of creating a copy was to perform operations on a separate list without directly modifying the original data.

Then, I used indexing to change specific values inside the `update_data` list. With the help of indexing, I was able to access and modify elements at particular positions.

Finally, I printed both lists (`data` and `update_data`) to clearly show the difference between the original and the updated list.
